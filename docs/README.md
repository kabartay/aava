| File | What it answers |
|---|---|

Start with STATUS.md if you want to know what you can play, ROADMAP.md if you
want to know what to do next, and LESSONS.md before changing anything — most of
its entries are properties of Godot rather than mistakes anyone made once.

All documentation, code, comments and identifiers are in English. The game
itself speaks English, French and Russian.
