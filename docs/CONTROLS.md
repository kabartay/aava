# Controls

The same actions on a tablet and on a desktop. Everything is on screen, because
a control a child has to be told about is a control he forgets.

| Action | Tablet | Desktop |
| --- | --- | --- |
| Move | left thumbstick — push further to go faster, past three quarters to run | `W A S D`, `Shift` to run |
| Look | drag anywhere | drag with the mouse |
| Zoom | pinch with two fingers | mouse wheel |
| Jump | **jump** button | `Space` |
| Gather | walk over it | walk over it |
| Kick | hold **kick**; look up to chip, down to drive | hold `E` |
| Build | **build**, then a tab and a piece, then `+` | same |
| Remove | `−` next to a piece | same |
| Map | tap it to cycle small, large, hidden | click it |
| Language, reset | `≡` top left | same |

## Things worth knowing

**Kick strength is how long you hold.** A tap nudges the ball a couple of
metres; a full hold reaches the goal from the halfway line. Running at the ball
adds to whatever the hold gave.

**Where you look is where it goes.** Looking level drives the ball along the
ground; looking up chips it. The words under the power bar say which.

**You build on the storey you are standing on.** Walk up, build up. The screen
says which floor the piece will land on.

**Removing gives everything back.** There is no penalty for trying something and
changing your mind — that is the point.

**Resetting the world is held for five seconds**, not pressed. The valley is
shared between brothers, and a button either of them can press deletes the
other's afternoon.
