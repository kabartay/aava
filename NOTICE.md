## What this means in practice

Fork it, change it, put your own name and your own icon on it, publish the
source, and you are welcome. Build the same game with the same name and the
same icon and hand it to a shop as though it were this one, and you are not —
that is the part a licence cannot do for you and a name can, because an app
store will act on a name and an icon long before it will read a licence.

The game is made for children and given away. If you want to do something with
it that this does not cover, the sensible thing is to ask.
